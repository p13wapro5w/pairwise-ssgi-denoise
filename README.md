# pairwise-ssgi-denoise

室内墙角本该有墙面的暖色反弹，现在却整片偏红，SSGI 只采了一次反弹，二次反弹能量直接按常数补；射线数按屏幕像素固定，近处过采样远处欠采样；时域重投影复用上一帧的辐照度却没做深度校验，角色走过墙面留下一块亮斑；降噪双边权重只看颜色差，法线相反的两个面被糊到一起；半分辨率追踪上采样没做深度保边，墙角出现光晕；金属表面的漫反射探针与屏幕空间结果直接相加，能量翻倍；屏幕外物体不参与追踪，走到画面边缘的红色墙突然失去反弹；HDR 辐照度进缓冲前被 clamp，霓虹灯附近的间接光发灰；探针更新按帧轮转，相机快速转身时墙面颜色滞后；多相机分屏共用一张 SSGI 历史，瞄准镜里的画面污染主视图。render/ssgi_denoise.py 是核心，tests/test_ssgi_denoise.py 15个红。要修的是：补二次反弹；射线按像素足迹分配；重投影校验深度法线；双边权重加法线项；上采样按深度保边；漫反射与镜面分开积分；屏幕外回退到探针；HDR 全链路；探针按视角优先级；多相机独立历史。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
